# 5. Alcance del MVP

## 5.1 Gestión de usuarios

- Registro de usuarios.
- Inicio de sesión.
- Autenticación.
- Roles.
- Control de acceso.
- Asociación del usuario con un negocio.
- Varios usuarios trabajando sobre el mismo negocio.

## 5.2 Gestión de productos

- Registrar productos.
- Consultar productos.
- Modificar productos.
- Baja lógica.
- Clasificación por categoría.
- Clasificación mediante etiquetas.
- Consulta del stock disponible.
- Definición de stock mínimo.
- Estado activo/inactivo.

La información de un producto contempla, entre otros datos:

- Nombre.
- Descripción.
- Precio de venta.
- Costo.
- Categoría.
- Etiquetas.
- Stock actual.
- Stock mínimo.
- Estado.

## 5.3 Gestión de ventas

- Registrar una venta.
- Seleccionar productos y cantidades.
- Calcular el total automáticamente.
- Registrar el usuario que realiza la operación.
- Registrar fecha y hora.
- Registrar medio de pago.
- Mantener el detalle de los productos vendidos.
- Actualizar el stock de los productos.

## 5.4 Estadísticas

- Cantidad de ventas.
- Facturación.
- Producto más vendido.
- Producto con mayor facturación.
- Producto con mayor ganancia.
- Estadísticas por distintos períodos.
- Productos con stock bajo.

## 5.5 Categorías y etiquetas

- Crear categorías.
- Consultar categorías.
- Crear etiquetas.
- Asociar múltiples etiquetas a un producto.
- Utilizar categorías y etiquetas para organizar y filtrar productos.

## 5.6 Fuera del alcance inicial

El MVP no incluirá:

- Facturación electrónica.
- Integración con medios de pago.
- Contabilidad completa.
- Gestión de proveedores.
- Aplicación móvil nativa.
- Integraciones con sistemas externos.
- Inteligencia artificial para predicción de ventas.

Estas funcionalidades podrán considerarse en futuras versiones.
