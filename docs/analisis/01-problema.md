# 1. Problemática

## 1.1 Problemática inicial

Los pequeños comercios pueden administrar sus productos, ventas y stock de forma manual o mediante herramientas que no están integradas entre sí. Esta situación puede dificultar mantener la información organizada, consultarla rápidamente y aprovecharla posteriormente para analizar el funcionamiento del negocio.

A partir de esta situación se realizó un relevamiento para conocer cómo se llevan adelante estas tareas en distintos pequeños comercios y validar las problemáticas iniciales.

## 1.2 Problemáticas a validar

- Dificultad para encontrar información rápidamente.
- Errores al registrar precios, cantidades o ventas.
- Falta de información histórica organizada.
- Dificultad para conocer qué productos se venden más.
- Dificultad para determinar qué productos generan una mayor ganancia.
- Falta de control sobre el stock.
- Dependencia de una única persona para conocer la información del negocio.

Estas situaciones fueron consideradas hipótesis iniciales y fueron contrastadas durante el relevamiento.
