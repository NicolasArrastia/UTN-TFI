# 3. Propuesta de solución

## 3.1 Solución propuesta

Se propone desarrollar una aplicación web de gestión comercial orientada a pequeños negocios.

El sistema permitirá centralizar la información relacionada con:

- Productos.
- Ventas.
- Stock.
- Categorías.
- Etiquetas.
- Usuarios.

Además del almacenamiento de información, los datos generados por las operaciones serán utilizados para obtener estadísticas sobre ventas, facturación, productos y stock.

Un mismo negocio podrá tener varios usuarios con diferentes niveles de acceso según las tareas que realicen.

## 3.2 Valor agregado

La propuesta no busca limitarse a digitalizar los registros manuales. Al registrar una venta, el sistema también permitirá:

1. Actualizar el stock.
2. Mantener un historial de operaciones.
3. Conservar el detalle de los productos vendidos.
4. Calcular información de facturación.
5. Identificar productos destacados por ventas, facturación o ganancia.

De esta manera, los datos registrados pueden transformarse en información útil para la gestión.

## 3.3 Propuesta de valor

- **Centralización:** la información principal del negocio se mantiene en un único sistema.
- **Digitalización:** se reduce la dependencia de registros manuales y herramientas dispersas.
- **Análisis:** las ventas registradas permiten generar estadísticas.
- **Colaboración:** varios usuarios pueden trabajar sobre la información del mismo negocio con permisos diferenciados.
- **Simplicidad:** el MVP prioriza las operaciones comunes de un pequeño comercio.

## 3.4 Público objetivo

El público objetivo inicial son pequeños comercios y emprendimientos que necesiten una herramienta sencilla para administrar productos, ventas y stock.

La solución está especialmente orientada a negocios que actualmente utilizan papel, cuadernos, registradoras, hojas de precios o herramientas separadas y necesitan centralizar la información.

## 3.5 Diferenciación

El proyecto no busca competir inicialmente con sistemas comerciales de gran escala.

Los principales diferenciadores son:

1. Simplicidad.
2. Baja curva de aprendizaje.
3. Estadísticas como parte central del sistema.
4. Soporte para múltiples usuarios y roles.

El diferencial principal será la combinación de facilidad de uso, centralización y aprovechamiento de la información.
