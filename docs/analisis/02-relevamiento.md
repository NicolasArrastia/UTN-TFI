# 2. Relevamiento

## 2.1 Objetivo

El relevamiento tuvo como objetivo conocer cómo se registran actualmente las ventas, los precios y la información de los productos en pequeños comercios, y comparar esas situaciones con las problemáticas planteadas inicialmente.

## 2.2 Comercios considerados

Se tomaron como referencia situaciones observadas en:

- Un mini mercado.
- Una panadería.
- Una carnicería.

Se eligieron porque presentan diferentes formas de trabajo y permiten observar distintas maneras de registrar y administrar la información.

## 2.3 Técnica

Se definió una serie de preguntas como guía para analizar:

- Cómo se registran las ventas.
- Qué herramientas se utilizan durante la atención.
- Cómo se consultan y administran los precios.
- Qué información queda registrada después de una venta.
- Qué procesos se realizan manualmente.
- Si la información registrada puede utilizarse posteriormente para analizar el negocio.

También se utilizaron observaciones derivadas del contacto habitual con estos comercios.

## 2.4 Resultados

### Mini mercado

El funcionamiento observado es principalmente manual. Se utilizan balanzas digitales y, cuando es necesario, calculadora o papel. También existe una hoja de precios como referencia y, ante productos nuevos, puede ser necesario consultar el precio entre los empleados. No se observó un sistema informático para registrar el detalle de las ventas.

### Panadería

Se utiliza una registradora y se entrega ticket. Además, se mantiene un registro en papel con la fecha y el monto de las operaciones. Los precios son normalmente conocidos por los empleados y también existe una hoja de consulta.

### Carnicería

Se utilizan registros manuales en un cuaderno donde se anotan principalmente la fecha y el monto de las operaciones.

## 2.5 Conclusiones del relevamiento

Aunque los comercios trabajan de maneras diferentes, se encontró como punto en común la presencia de procesos manuales o información distribuida entre distintas herramientas.

También se observó que registrar solamente la fecha y el monto de una operación no permite conocer posteriormente qué productos formaron parte de la venta. Esto limita la posibilidad de obtener automáticamente información como productos más vendidos, rendimiento de productos o actualización del stock.

Por lo tanto, el problema identificado está relacionado no solamente con reemplazar el papel por una aplicación, sino con registrar y centralizar información suficientemente detallada para poder utilizarla posteriormente.
